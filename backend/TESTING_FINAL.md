## 🚀 Как запустить тесты

### Быстрый запуск
```bash
cd backend
export DJANGO_SETTINGS_MODULE=config.settings
./run_all_tests.sh
```

### С покрытием кода
```bash
cd backend
export DJANGO_SETTINGS_MODULE=config.settings
./run_all_tests.sh --cov
```

### Отдельные приложения
```bash
# Users
pytest apps/users/tests/test_user_models.py

# Projects  
pytest apps/projects/tests/test_project_models.py

# Applications
pytest apps/applications/tests/test_application_models.py

# Reports
pytest apps/reports/tests/test_report_models.py
```

## 🏗️ Архитектура тестирования

### ✅ Реализовано:

1. **pytest + pytest-django** - основной фреймворк тестирования
2. **factory_boy** - генерация тестовых данных
3. **pytest-mock** - мокирование внешних сервисов
4. **pytest-cov** - измерение покрытия кода
5. **GitHub Actions CI** - автоматическое тестирование
